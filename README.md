# AI Advent

Интерактивная CLI-утилита, которая отправляет сообщения через OpenAI Python SDK и выводит ответы в консоль. Можно использовать OpenAI или другой OpenAI-compatible endpoint, например DeepSeek или Z.ai. Контекст сохраняется в течение запущенной сессии.

## Установка

Требуется Python 3.10 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

Создайте `.env` на основе примера и укажите API-ключ:

```bash
cp .env.example .env
```

```dotenv
AI_ADVENT_API_KEY=sk-your-api-key
AI_ADVENT_MODEL=gpt-5.6-luna
AI_ADVENT_BASE_URL=https://api.openai.com/v1
```

Файл `.env` исключён из Git и не попадёт в репозиторий.

## Запуск

Обычный чат из дня 1:

```bash
ai-advent
```

Введите сообщение и нажмите Enter. Для завершения используйте `/exit`, `/quit` или `Ctrl+D`.

Модель и провайдера можно менять через `.env`:

```dotenv
AI_ADVENT_API_KEY=your-provider-api-key
AI_ADVENT_MODEL=deepseek-chat
AI_ADVENT_BASE_URL=https://api.deepseek.com
```

Для OpenAI-compatible API используются те же вызовы SDK: меняются только ключ, модель и `base_url`.

## День 2: формат ответа

Сценарий дня 2 отправляет один и тот же запрос два раза:

- без ограничений;
- с явным описанием JSON-формата, ограничением длины и условием завершения.

```bash
ai-advent compare-format
```

По умолчанию используется вопрос:

```text
Расскажи про город Сызрань.
```

Можно передать другой вопрос о городе:

```bash
ai-advent compare-format "Расскажи про город Казань."
```

Контролируемый ответ запрашивается строго в JSON:

```json
{
  "summary": "Короткая общая информация о городе",
  "facts": ["Факт 1", "Факт 2", "Факт 3"],
  "year_of_foundation": 1683,
  "population": 165000
}
```

Условие завершения задается инструкцией: ответ должен закончиться сразу после
закрывающей фигурной скобки JSON-объекта, без дополнительного текста.

## День 3: разные способы рассуждения

Сценарий дня 3 решает одну аналитическую задачу четырьмя способами:

- прямой ответ без дополнительных инструкций;
- ответ с инструкцией решать пошагово;
- сначала генерация промпта для решения, затем решение по этому промпту;
- решение через группу экспертов.

```bash
ai-advent compare-reasoning
```

По умолчанию используется задача:

```text
Составь идеальный завтрак для среднестатистического гражданина РФ.
```

Можно передать другую аналитическую задачу:

```bash
ai-advent compare-reasoning "Составь идеальный завтрак для студента в Японии."
```

В конце CLI отправляет отдельный запрос на сравнение всех ответов и просит
выбрать наиболее точный способ по критериям культурной уместности,
питательности, доступности продуктов, умеренной стоимости и практичности утром.

## День 4: температура

Сценарий дня 4 отправляет один и тот же запрос с тремя значениями
`temperature`:

- `0`;
- `0.7`;
- `1.2`.

```bash
ai-advent compare-temperature
```

По умолчанию используется запрос:

```text
Придумай короткое описание нового кафе в центре города Минск, которое специализируется на завтраках.
```

Можно передать другой запрос:

```bash
ai-advent compare-temperature "Придумай три названия для кофейни у вокзала."
```

В конце CLI сравнивает ответы по точности, креативности и разнообразию, а
также формулирует, для каких задач лучше подходит каждая настройка.

## День 5: версии моделей

Сценарий дня 5 отправляет один и тот же запрос в несколько GLM-моделей через
OpenAI-compatible API и замеряет:

- время ответа;
- `prompt_tokens`, `completion_tokens` и `total_tokens`, если API вернул usage;
- примерную стоимость по публичным тарифам Z.ai за 1M input/output tokens;
- качество ответов через отдельный запрос к модели-судье.

```bash
ai-advent compare-models
```

По умолчанию используются модели:

- `glm-4.5-flash`;
- `glm-4.5-air`;
- `glm-5`.

По умолчанию используется задача:

```text
Ты продуктовый аналитик. Напиши короткую спецификацию MVP для приложения “AI Advent Tracker” — сервиса, который помогает новичкам проходить 30-дневный челлендж по изучению AI.

Нужно включить:
1. Целевая аудитория.
2. Главная проблема пользователя.
3. 5 ключевых функций MVP.
4. Что НЕ входит в MVP.
5. Простая пользовательская история.
6. 3 метрики успеха.
7. 3 риска и способы их снизить.

Ограничение: до 900 слов. Пиши конкретно, без маркетинговой воды. Верни только спецификацию, без дополнительных вопросов.
```

Для Z.ai удобно указать такие настройки:

```dotenv
AI_ADVENT_API_KEY=your-zai-api-key
AI_ADVENT_BASE_URL=https://api.z.ai/api/paas/v4/
AI_ADVENT_MODEL=glm-4.5-air
```

Можно заменить запрос:

```bash
ai-advent compare-models "Объясни, как работает RAG, на примере библиотеки."
```

Можно заменить список моделей:

```bash
ai-advent compare-models --models glm-4.5-flash,glm-4.5-air,glm-5.1
```

Или выбрать отдельную модель для финального сравнения качества:

```bash
ai-advent compare-models --judge-model glm-5
```
